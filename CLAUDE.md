# harbour

Curated torrents straight from your terminal. A Rust TUI client.

## Stack

- Rust
- TUI (ratatui)

## Commands

```bash
cargo build
cargo run
cargo test
cargo clippy -- -D warnings
```

## Rules

- Lean dependency tree. Justify every new crate.
- `cargo fmt` + `cargo clippy -- -D warnings` clean before commit.
