# How to use Harbour

This is the simple version. Press `?` inside the app for the same steps.

## What this is

Harbour is a program that runs in a terminal window. You type a name, it finds torrents, you can **watch** or **download**.

You need a **video player** on your computer. **VLC** is the easiest: https://www.videolan.org/

## First time

1. Open Harbour (`harbour` or `harbour.exe`).
2. Press **Enter** to skip the splash.
3. Type something (try `sintel`) and press **Enter**.
4. Click a result, or press **Enter** / **w** to watch.
5. A box appears: **choose a video player**.
   - Click **VLC** (or **mpv**).
   - Or press **1**, **2**, **3** for the numbered list.
   - Harbour remembers. You will not be asked every time.

If the list is empty: install VLC, then press **r** in that box, or press **c** and type the full path to `vlc.exe`.

## Everyday

| You want to… | Do this |
| --- | --- |
| Search | Type, then Enter |
| Watch | Enter or **w** on a result |
| Download | **d** |
| Change player | **Shift+P**, or **s** then the first row, click / Enter |
| Downloads list | **Tab** |
| Open the files | Double-click a download, or **o** / **Enter** |
| Help | **?** |
| Quit | **q**, then yes |

## Sources on the left

Each site can be **on** or **off**. Click a name to flip it. Off sites are skipped.

## If watch does nothing

1. Install VLC.
2. Press **Shift+P** and click it.
3. The file must be a video (not a `.zip`). Games are downloads, not watch.
