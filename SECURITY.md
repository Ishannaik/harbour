# Security Policy

harbour fetches torrents from remote sources and runs in your terminal.

## Reporting a vulnerability

Open a GitHub issue, or email the maintainers directly if you believe the
issue is sensitive. Do not post credentials or tokens in public issues.

## What matters here

- Anything that lets a malicious torrent source execute code or write
  outside expected paths.
- Leaks of any API keys or tokens the client stores.
